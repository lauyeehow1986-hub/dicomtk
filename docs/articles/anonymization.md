# DICOM Anonymization & HIPAA De-identification

## Overview

`dicomtk` implements HIPAA Safe Harbor and the **DICOM PS3.15 Basic
Application Level Confidentiality Profile** via
[`dicom_anonymize()`](https://lauyeehow1986-hub.github.io/dicomtk/reference/dicom_anonymize.md).
Unlike legacy wrappers that invoke external `dcmodify` subprocesses,
`dicomtk` performs de-identification natively in C++17 memory.

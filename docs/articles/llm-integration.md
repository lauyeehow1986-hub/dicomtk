# AI & LLM Integration: Local Ollama, OpenAI, and Anthropic Claude

## Overview

`dicomtk` connects DICOM metadata and pixel data to both **local LLMs**
(via [Ollama](https://ollama.com)) and **OpenAI-compatible cloud or
subscription endpoints** (OpenAI, Anthropic Claude, OpenRouter, LM
Studio, vLLM, Azure OpenAI).
